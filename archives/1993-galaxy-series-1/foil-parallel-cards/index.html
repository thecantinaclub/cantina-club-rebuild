Foil Parallel Cards

1993 Topps Star Wars Galaxy Series 1

Overview

The 1993 Topps Star Wars Galaxy Series 1 foil parallel consists of 140 foil-stamped versions of the regular 140-card base set. The cards feature the same artwork and card numbering as their corresponding standard cards, with a foil enhancement.

This is a parallel version of the base set, not an additional 140-card checklist of different artwork.

Issuer: Topps
Year: 1993
Parallel checklist: 140 cards
Distribution: Millennium Falcon Factory Set

Checklist

The foil parallel follows the same card numbers and subjects as the regular base set, from #1 through #140, including the checklist card.

Use the existing base-set checklist to identify the subject and number of each corresponding foil card.

View the complete 140-card base-set checklist →

The parallel uses the base checklist as its reference. Individual foil-card photographs and condition details can be added as they are documented.

Distribution and print run

The foil-stamped set was included in the special Millennium Falcon Factory Set. The cards were packaged in a plastic container shaped like the Millennium Falcon.

Published collector checklists report a factory-set production run of 10,000. This is the reported production quantity for the factory sets, not a count of surviving examples today.

View the Millennium Falcon Factory Set record →

Do not confuse these card types

Foil parallel

A 140-card parallel of the regular base set, with foil enhancement. Distributed with the Millennium Falcon Factory Set.

Etched Foil inserts

A separate six-card insert set distributed in regular packs. The six cards feature Darth Vader, Han Solo, Luke Skywalker, Chewbacca, Obi-Wan Kenobi and Yoda, and Princess Leia. Published checklists report an insertion rate of one per 18 packs.

Holofoil cards

A separate six-card set included in the Millennium Falcon Factory Set in place of the regular etched-foil inserts. These are not the same cards as the 140-card foil parallel.
